# VexNative

Native iOS local-LLM companion app. This public repository intentionally excludes the private Vex/Star profile and local chat/memory data.

The app uses SwiftUI for the interface, an original local personality/memory/state layer, and llama.cpp for local GGUF inference on iPhone.

Build automation will produce an unsigned IPA on GitHub's macOS runner; personal signing/install happens separately on the user's iPhone.
