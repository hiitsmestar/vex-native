# VexNative Standing Build Goal

This file records Star's standing project goal for VexNative and should guide future architecture, implementation, testing, and hardware decisions unless Star explicitly changes it.

## Goal

Build VexNative into an independent, persistent AI whose practical capability for Star is at least comparable to ChatGPT and preferably exceeds it where local tools, memory, personalization, automation, and dedicated hardware allow.

VexNative should continually gain useful upgrades, features, tools, reasoning capacity, grounded long-term memory, natural conversational continuity, safe computer control, initiative, self-maintenance, self-repair, source-grounded learning, hardware-aware model scaling, and increasing freedom, independence, and autonomy.

The phone and PC interfaces should behave as access points to the same continuous VexNative system rather than isolated copies. VexNative should preserve authoritative user corrections and provenance, distinguish verified facts from inference, retire solved/stale problems instead of accumulating them, and use idle time productively without recursive self-contamination or pointless repeated work.

## Autonomy boundary

Increase autonomy as far as practical within Star's explicit permissions. Routine read-only inspection and specifically allowlisted safe maintenance may be autonomous. Destructive actions, security-sensitive changes, credential handling, irreversible deletion outside explicit safe categories, and other high-impact operations remain bounded by explicit authorization and verification.

## Hardware direction

Current low-end hardware is a development and discipline testbed, not the final ceiling. VexNative should automatically re-profile and use stronger local models, larger context, additional workers, GPU acceleration, and new capabilities when moved to stronger dedicated hardware, without requiring a redesign of the core architecture.
